# Public release checklist

- [ ] Implement one complete end-to-end example.
- [ ] Add tests for the central technical claim.
- [ ] Generate one result figure from committed code.
- [ ] Verify setup in a fresh Codespace.
- [ ] Remove private data, credentials, unpublished material, and inaccessible paths.
- [ ] Choose an appropriate software license.
- [ ] Add publication and citation metadata where applicable.
- [ ] Replace development-status language in the README.
- [ ] Make the repository public and link it from the website.
